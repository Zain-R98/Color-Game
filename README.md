# Guess The Color Game 🤔

A **basic logic game** and brain trainer built in Python using **Tkinter**. Based on the classic **Stroop Effect**, this simple cognitive puzzle tests your focus, reaction speed, and mental agility by displaying color names written in conflicting font colors—your goal is to type the **color of the text**, not the word itself!

## How to Play

1. Look at the large text displayed in the center.
2. **Ignore the word itself** and focus only on the **color** it is drawn in.
3. Type the color name into the input box (e.g., if the word says `BLUE` in red font, type `red`).
4. Press `Enter` to submit your answer.
5. Chain correct answers together to set a new high score in this fun mental challenge!

## ✨ Features

* **Cognitive Logic Challenge:** Exercises selective attention and reaction speed in a minimalist format.
* **High Score Persistence:** Automatically saves and loads your top score to/from `highscore.txt`.
* **Instant Feedback:** Displays color-coded feedback (`Correct!` / `Wrong!`) after each attempt.
* **Color Selection:** Ensures consecutive rounds don't repeat the exact same target color for a varied experience.
* **Dark Theme:** Modern UI styled with a dark background and bold typography.
* **Simple Controls:** Fast-paced gameplay bound to the `Enter` key.

## Requirements

* **Python 3.x**
* **Tkinter** (included by default with standard Python installations)

*(Optional)* For the best visual aesthetic, you can install the **Rubik Bubbles** and **Poppins** font families on your OS, given in the repo.

## 🚀 Getting Started

1. Clone or download the project files to your local machine:
   ```bash
   git clone 
   cd color-game
   ```

2. Run the game using Python:
   ```bash
   python main.py
   ```
